## Five Nights at Freddy's: 2D!

Projeto em desenvolvimento de um fangame 2D de visão Top-Down do Five Nights at Freddy's (2014), feito pela Unity para a matéria de Programação para Jogos!
Este é um fan game feito sem fins lucrativos, para fins acadêmicos. Não é afiliado, patrocinado ou endossado por Scott Cawthon ou Steel Wool Studios. 
Five Nights at Freddy's e seus personagens pertencem aos seus respectivos donos.

## Sobre o jogo

A energia da pizzaria acabou durante o seu turno de vigilância. Você precisa percorrer o estabelecimento, coletar os fusíveis espalhados e voltar à cabine de segurança para restaurar a energia, tudo isso enquanto os animatrônicos circulam pelo local. A cada noite, a quantidade de fusíveis, o número de animatrônicos e a dificuldade aumentam.

## Tecnologias
- Unity 6 com o template Universal 2D (URP)
- C# para a programação dos scripts
- Light 2D e Shadow Caster 2D para a iluminação
- Git e GitHub para versionamento

## Status do projeto

## Como executar
- Instale o Unity Hub e a versão 6 do Unity Editor (módulo 2D).
- Clone o repositório:
   git clone https://github.com/1KPN/FNAF-2D.git
- No Unity Hub, clique em Add > Add project from disk e selecione a pasta clonada.
- Abra a cena principal em Assets/Scenes e clique em Play.
